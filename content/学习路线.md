# 择日项目学习路线

课程以完成实际择日任务为主线。开始时不必先通读34章知识，先选项目、接清任务，再按步骤学习本步需要的查法。第一个项目从较简单的节后复工选时入手。

## 你将依次做什么

| 项目 | 完成的任务 | 增加的能力 |
|---|---|---|
| [项目1](#zp-01) 开市复工 | 比较两个候选时辰，写出弃取理由 | 分用事、日课、年命，先筛日再核时与人 |
| [项目2](#zp-02) 搬家入宅 | 排正式用事时点与入宅记录 | 在日家与人物之外增加坐山 |
| [项目3](#zp-03) 安床 | 单独完成床的起用核验 | 男官女食、出生月柱胎元、位置范围 |
| [项目4](#zp-04) 嫁娶 | 女命选月、双方配课、仪式分时 | 多人物、多环节与具体制化条件 |
| [项目5](#zp-05) 修造安门 | 工程动作、山方与时间逐项对应 | 动土、起基、上梁、新坐旧方分开 |
| [项目6](#zp-06) 安葬事务 | 按动作分别核人物、山家和日时 | 仙命祭主、不同用事与专业复核 |

## 每个项目怎样学

1. 先读任务和最后要交什么，不急着看所有名词。
2. 收集人物、地点、时间范围与实际动作；课程例子中已给出的输入可以直接跟做。
3. 到哪一步再展开哪张知识表，学会选行、找参照、写结果。
4. 跟做原课例子或明确的局部规则演算；不把缺时柱的例子补成真实全课。
5. 换成自己的任务，逐项记录取舍、缺项与复核理由，再安排实际执行。

能读懂课程不应依赖另看原PDF或讲课。实际任务仍需取得真实坐山、人物年命、候选日期的历法及通书日时字段；这些是任务输入。课程未给出某日的完整资料时，不假装已经全部核定。例子里明确的原文差异保留，归纳步骤不冒充原书额外规则。
