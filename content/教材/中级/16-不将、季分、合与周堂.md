# 第16章 不将、季分、合与周堂

> **前置**：先完成第15章；可按目录回看相关基础。
> **本章解决什么**：能区分不同“合”，知道不将阴阳不是普通干支阴阳。
> **本章的一句话**：能区分不同“合”，知道不将阴阳不是普通干支阴阳。

## 一、先把问题讲清楚

嫁娶的有利条件包括不将、季分、三合、五合、六合和七合，但这些名称并非一套算法。不将从月厌、厌对划分阴阳区，再按季节处理戊己；季分有逐月固定日表；周堂则按农历日数和大小月另推。

五合在这里常指十个寅卯日组成的天地、日月、人民、金石、江河合，不等同于甲己、乙庚的天干五合。人民合为戊寅、己卯，是嫁娶常用的一组。六合在日家层面，原课特别强调月日相合；七合还把男女命和女命天嗣带入。

不将中的“阳干”“阴支”是相对月厌图的位置命名，不能直接用甲丙戊庚壬阳干表替换。原稿个别段落对图前后方向有不一致，初学先会按逐月明确表与完整范例核验；争议图法不据此出机械计算题。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 月厌 | 寅月起戌，逐月逆行十二支 |
| 厌对 | 月厌的对冲支 |
| 人民合 | 戊寅、己卯 |
| 天地合 | 甲寅、乙卯 |
| 月日六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 |
| 七合 | 男女命与日期相合，并天嗣再合 |
| 周堂 | 阴历日数及大小月另推 |

## 三、实际怎么检查

1. 先定实际月建，查当月月厌与厌对。
2. 不将按明确逐月表或完整图例核，注意季节戊己条件。
3. 把每种合写上所属系统，避免同名互代。
4. 周堂另核农历大小月和日数，不拿日干支替代。

### 手算练习：月厌与厌对先定位，不急着配日

寅月月厌起戌，下一月逆行一支为酉，再下一月为申；厌对则各取六冲，所以寅月是戌辰，卯月是酉卯，辰月是申寅。做到这里只是把分区起点定位，还没有完成不将日列表。接下来仍须按原图确定前后阴阳区、季节戊己和合法干支配对，不能用普通阳干表直接跳到结论。

## 四、原课例子与拆解

p891–892以壬寅年丁未月甲戌日说明未月不将：先找月厌巳、厌对亥，再按夏季加入戊干，列出甲午、甲申、甲戌等相配日。它不是用甲阳、戌阳就判阳将。p257则另给戊寅己卯为人民合，与这套月厌分区是两回事。

## 五、易错与适用边界

p253强调优先不将，p892又说合不上不将时可看其他指定吉神。两段可按优先选择与候选不足时的处理理解，但不能扩成“任何吉星都能解俱将”。月厌图方向的歧义单列，不擅自定一套新算法。
