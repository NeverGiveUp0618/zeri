# 第17章 嫁娶六神：以女命年干辨制化

> **前置**：先完成第16章；可按目录回看相关基础。
> **本章解决什么**：能确定十神坐标，并区分伤官、偏印、七杀的制化对象。
> **本章的一句话**：能确定十神坐标，并区分伤官、偏印、七杀的制化对象。

## 一、先把问题讲清楚

嫁娶六神论以女命年干为“我”，检查日课四天干的关系。它不是拿日课日干给整课定十神，也不是把盲派断命里的体用流程整体搬过来。坐标一错，伤官、夫星、天嗣的位置都会随之错。

原课重点处理伤官、偏印、七杀及官杀混现。伤官关系到夫星，偏印关系到食神子星，七杀另查印化、食神制等具体手段。处理时必须写出谁克谁、用哪个字泄或制、是否又相合而改变制约，不能只写一个“有制”。

相泄、相克、相耗是原课对制约途径的比较。选择哪种方式仍要看阴阳、十神和具体组合。尤其某个财干能否制偏印，原课分阴女阳女，并提醒有合可能无制，不允许把一句“财能制枭”当全盘通则。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 坐标 | 女命出生年干 |
| 伤官 | 主要查其对夫星的影响 |
| 偏印 | 主要查其对天嗣食神的影响 |
| 七杀 | 核印化、食神制及数量条件 |
| 官杀混现 | 另作一项检查，不以官星吉名覆盖七杀 |
| 制化记录 | 凶神、制神、具体生克与相合条件分别写出 |

## 三、实际怎么检查

1. 写女命年干，逐个标出日课四天干的十神。
2. 找出伤官、偏印、七杀及官杀并见的实际组合。
3. 按对应专条找制神，核阴阳、数量与是否合住。
4. 制化后再核地支冲合与其他婚嫁忌项，不以天干通过替代全课。

## 四、原课例子与拆解

p977起用女命年干与日课天干讨论六神，p978–980分别展开伤官、枭印、官杀。学习时把每例改写成四格：女命年干、所见凶神、承担制化的字、为什么成立。原课没有提供的婚后实际反馈，不补成已经验证的结果。

## 五、易错与适用边界

原资料只对特定组合给制法，不把一个例子扩成全部女命通用。主命支和日课地支也不能因天干有制便省略。对有争议、无完整条件的组合不出确定题。
