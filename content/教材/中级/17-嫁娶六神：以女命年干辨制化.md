# 第17章 嫁娶六神：以女命年干辨制化

> **前置**：先学 [第2章](#zr-02)、[第14章](#zr-14)、[第15章](#zr-15)。
> **本章解决什么**：能确定十神坐标，并区分伤官、偏印、七杀的制化对象。
> **本章的一句话**：以女命年干为“我”定十神，再写清哪个字泄、克或合了哪个凶神。

## 一、先把问题讲清楚

嫁娶六神论以女命的出生年干为“我”，去看日课四个天干与她的关系。原文开头即写明“女之年命论之”，所以十神的坐标是女命年干，不是日课的日干。坐标一错，伤官、夫星、天嗣的位置全部跟着错。

原文重点处理的是伤官、偏印、七杀，以及官杀混现。伤官关系到夫星，偏印关系到食神（子星），七杀需要看印化、食神制化或合化。每一种凶神都要写出：谁克谁、用哪个字泄或制、是否又有相合而改变了制约。只写一个“有制”二字不够。

制约的途径有相泄、相克、相耗三种。原文比较三者的力量：相泄最强，相克次之，相耗最弱，因此“能用泄不用克，能用克不用耗”。选择哪种方式，仍要看阴阳、十神和具体组合，不能看到财就当作能制一切。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 坐标 | 女命出生年干 |
| 伤官 | 有制为伤官，无制为克夫；主要查其对夫星的影响 |
| 偏印 | 有制为偏印，无制为枭印；主要查其对食神（子星）的影响 |
| 七杀 | 有制为偏官，无制为七杀；核印化、食神制及数量条件 |
| 官杀混现 | 另作一项检查，不以官星吉名覆盖七杀 |
| 忌见 | 资料列为忌讳的四种：伤官、偏印、七杀、官杀混现 |

### 十神以女命年干定名

| 相对女命年干 | 同性 | 异性 |
|---|---|---|
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |
| 生我 | 偏印 | 正印 |
| 我生 | 食神 | 伤官 |
| 同我 | 比肩 | 劫财 |

### 伤官与偏印的制化手段

- **伤官**：宜取正财来泄，或取正印来克；阳女可用偏印合化，阴女可用七杀合化（PDF第978至979页）。
- **偏印（枭印）**：阳女取正财、偏财、比肩、劫财、伤官来制；阴女取正财、比肩、劫财可解。偏财制偏印不宜合，合则无制（PDF第979至980页）。
- **七杀**：取印或食神来制；阴女用伤官合化，阳女用劫财来合化。两杀齐见，宜取双制或双化（PDF第977、981页）。

### 制一个条件时，再查是否引入另一个条件

七杀用印泄、食神克，是两条不同路径。第981页提醒，若取偏印化杀，偏印本身还须有制；无法满足时另考虑正印，不能因为已经化杀便把新出现的枭印问题删掉。两杀齐见要双制或双化，不能只见一个制字就一律算处理完。

官杀混杂要求制杀留官；正官重现则合化或脱泄一重，不是只要叫正官便越多越好。第977页的食神与伤官定义还决定天嗣取法，十神坐标从头到尾保持女命出生年干。

## 三、实际怎么检查

1. 写下女命出生年干，逐个标出日课四个天干的十神。
2. 找出伤官、偏印、七杀，以及官杀并见的实际组合。
3. 对照对应的制化条件，核阴阳、数量和是否被合住。
4. 制化之后，再核日课地支的冲合与其他婚嫁忌项，不能因为天干有制就省略全课。

## 四、原课例子与拆解

**甲子女的伤官例（PDF第978至979页）。** 甲子女，庚子年乙酉月乙亥日丁亥时。丁为伤官，甲的正官是辛，丁克辛，所以伤官克官。己是甲的正财，己土泄丁火，用的是泄法；癸是甲的正印，癸水克丁火，用的是克法。资料认为泄比克好，所以先用正财。此课只要天干中见己或癸即可。另有丁壬五合的情形，壬是甲的偏印，因合而化。

**甲子女的枭印例（PDF第980页）。** 壬为甲的枭印，丁为伤官，丙为食神。壬水克丙火，所以对子女不利。课中若有己土，只是正财，克壬力量较小；戊土为偏财，克壬力量大；甲木为比肩，泄壬力量大；乙木为劫财，泄壬力量小；若有丁火，丁壬合，也能制枭印。

**乙丑女的七杀例（PDF第981页）。** 乙丑女，辛丑年结婚，辛为七杀，用伤官丙来合化，丙辛相合。阴女用伤官合杀。

原文没有给出婚后的实际反馈，所以本章只写制化的条件，不写结果。

## 五、易错与适用边界

- **同一年干的制法不能互换。** 阳女与阴女的偏印、七杀制法不同，偏财对阳女与阴女的适用也不同，不能只记“财能制枭”。
- **合化可能失去制约。** 原文提醒偏财制偏印“不宜合，合则无制”，合化是否仍能制，要看具体条件。
- **官杀混现的取舍。** 资料说“制杀留官，不可制官留杀”。有几个七杀就制化几个，但不能用官星的吉名遮掉七杀。
- **通书宜忌不能替代六神。** PDF第982页说只看通书选日子太机械，通书宜嫁娶只是参考范围；选定后仍要按利月、六神等逐项核。
- **有争议的组合不出确定题。** 原文对某些组合（如阴女偏印的财干取法）的表述有细节差异，学习时以明确的例子为准，不拿一句话推成全通则。

## 七、本章小结

- 以女命出生年干为坐标，写出日课四个天干各自的十神。
- 伤官、偏印、七杀、官杀混现四项要逐一检查，不能只写“有制”。
- 制化分泄、克、耗、合，力量比较是泄最强、克次之、耗最弱。
- 阴女与阳女的偏印、七杀制法不同，合化可能使制约失效。
- 天干有制仍要核地支冲合与其他嫁娶忌项，不因此省略全课。
