# 第18章 天狗白虎占宫与吉时的具体到位

> **前置**：先完成第17章；可按目录回看相关基础。
> **本章解决什么**：能分清年神占宫、命宫定位与到方制化，不把吉名当实际到位。
> **本章的一句话**：能分清年神占宫、命宫定位与到方制化，不把吉名当实际到位。

## 一、先把问题讲清楚

嫁年天狗白虎的检查有两套定位：一套从嫁年太岁顺数十二神，另一套从女命禄位逆推命宫系统。之后才比较白虎、天狗是否占一、五、七宫。先算哪套都可以，但必须把两个起点和方向分别写清，不能数到一个白虎字便说占夫妻宫。

制化也要落到具体位置。麒麟星到方、太阳到方、贵人登天时各有自己的起法和时间条件。一个时辰恰好叫贵人时，不代表自动等同于贵人登天；通书有太阳名，也不代表太阳正在该方。

月将与月建在本章尤其容易混。贵人登天等使用月将的项目，原课强调相应中气分界。不能把前面排月柱的十二节分界原封不动挪来。先确认是哪种吉时，再查它需要的参数。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 年神 | 从嫁年太岁顺数十二神；白虎第九，天狗第十一 |
| 命宫 | 女命禄位起命宫，逆推各宫 |
| 重点宫位 | 一命宫、五男女宫、七夫妻宫 |
| 吉时核验 | 名称、起点、顺逆、节令、到达位置 |
| 月将 | 按所用表的中气口径，与排月柱月建分开 |
| 制化边界 | 具体到位，不以吉名替代算法 |

## 三、实际怎么检查

1. 列嫁年支和女命年干，分别排年神与命宫。
2. 对照一五七宫，记录到底哪神占哪宫。
3. 按原表查可用制法，核节令、时辰和到方。
4. 把制化过程及仍待核的婚嫁项目写在同一记录中。

### 手算练习：用给定参数练两套起点

以下只是按规则演算：给定嫁年支子，太岁从子起第一位顺数，白虎第九落申，天狗第十一落戌。再给女命年干甲，甲禄在寅，以寅为一命宫逆推：寅一、丑二、子三、亥四、戌五、酉六、申七。于是这个局部练习中白虎申对应七宫，天狗戌对应五宫。这个结果只识别占宫，尚未给完整日课或到方制化条件，不据此判实际婚期。
