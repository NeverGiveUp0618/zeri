# 第18章 天狗白虎占宫与吉时的具体到位

> **前置**：先学 [第4章](#zr-04)、[第10章](#zr-10)、[第14章](#zr-14)。
> **本章解决什么**：能分清年神占宫、命宫定位与到方制化，不把吉名当作实际到位。
> **本章的一句话**：嫁年的天狗白虎与女命的命宫各自排定，再核是否占一、五、七宫，制化要落到具体的时辰和方位。

## 一、先把问题讲清楚

天狗白虎占宫的检查有两套定位：一套从嫁年太岁起数十二神，另一套从女命禄位起命宫、逆行数宫。两套各自算出位置后，再看白虎、天狗是否落在一、五、七宫。原文规定忌占的是一、五、七宫，即命宫、男女宫、夫妻宫。

原文的例子是甲子女在子年结婚：子年起太岁，顺数到白虎在申、天狗在戌；甲禄在寅，寅为一命宫，逆行得五男女宫在戌、七夫妻宫在申。于是白虎占夫妻宫，天狗占男女宫（PDF第297页）。两套起点与方向必须分别写清，不能数到一个“白虎”字就说它占夫妻宫。

制化要落到具体位置。麒麟星到方、太阳到方、贵人登天时各有自己的起法和时间条件，要先确定是哪一种，再查它所需的参数。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 年神 | 从嫁年太岁顺数十二神，白虎为第九，天狗为第十一 |
| 命宫 | 从女命禄位起一命宫，逆行数至五男女宫、七夫妻宫 |
| 忌占 | 白虎或天狗占一、五、七宫，原文称为“忌占” |
| 贵人登天时 | 月将放在当日贵人位，顺数至天门亥，所临地支即是 |
| 麒麟到方 | 按节气与时辰查表，或用月将顺推到麒麟方 |
| 麒麟凤凰时 | 按日支查表，犯天狗用麒麟时，犯白虎用凤凰时 |
| 制化边界 | 以具体到位为准，不以吉名替代算法 |

## 三、实际怎么检查

1. 列出嫁年支，从太岁起顺数，记下白虎与天狗的位置。
2. 列出女命禄位，起命宫并逆行，记下一、五、七宫各是什么。
3. 对照两组位置，看哪一神占哪一宫。
4. 如有需要制化，按所选的时辰核麒麟到方、贵人登天时或麒麟凤凰时，并写明采用的口径。

### 手算练习：按原例练两套起点

沿用PDF第297页的甲子女例。嫁年支为子，太岁在子，顺数九位得白虎在申，数十一位得天狗在戌。甲女的禄在寅，以寅为一命宫，逆行：寅一、丑二、子三、亥四、戌五、酉六、申七，故五男女宫在戌、七夫妻宫在申。白虎申占七宫，天狗戌占五宫。这一练习只完成了占宫的识别，尚未查日课和时辰的制化，不能据此判断实际的婚期。

## 四、原课例子与拆解

**占宫的例子（PDF第297页）。** 见上文甲子女例：白虎占夫妻宫申，天狗占男女宫戌。

**贵人登天时（PDF第298至299页）。** 贵人登天指天门亥（地户为巳）。方法是：把月将放在当日天乙贵人所在的位置，顺数到亥，所临的地支即为贵人登天时。例如小满后月将在申，甲日的阳贵为丑、未，由丑上起申顺行至亥得午，由未上起申顺行至亥得子，所以午、子二时为贵人登天时，每日两时。

**麒麟凤凰时（PDF第1447页）。** 按日支查表：子午日凤凰时为子、麒麟时为午；丑未日为寅、申；寅申日为辰、戌；卯酉日为午、子；辰戌日为申、寅；巳亥日为戌、辰。资料说明犯天狗用麒麟时，犯白虎用凤凰时。

## 五、易错与适用边界

- **月将不等于月建。** PDF第1444页明确：月将正月从雨水起，二月从春分起，不按立春、惊蛰的界线。学过排月柱不等于会推月将，两者的节令界线不同。
- **贵人时辰要分清。** 一个时辰恰好是贵人所在的时，不等于贵人登天时。贵人登天是按月将推得的时辰，不能只凭时辰名称判断。
- **阴阳贵人的查表。** PDF第299页给出阳贵人歌诀与阴贵人歌诀，PDF第300页为按节气列出的阳贵、阴贵速查表，行数较多，本章不逐格抄录，使用时按原表对照。
- **一条数据的疑问。** PDF第299页的大雪甲日例中，“将寅放在未，数到亥，子为阴贵人登天时”一句的“阴贵”与前一句的阳贵人位是否对应，原文没有解释，应以速查表核对，不据此推断。
- **麒麟凤凰与白虎天狗的配法有不同讲法。** PDF第1447页又说犯白虎用麒麟时也可以，因此“犯天狗用麒麟，犯白虎用凤凰”是原文的主要配法，不是唯一配法。
- **女命禄马与驿马在日上。** PDF第301页的丙寅女例说明，申为丙寅女的马星，与寅相冲，马星在日或时都不理想。这一点见于女命禄马贵一条，与占宫不同，不要混用。

## 七、本章小结

- 年神从嫁年太岁顺数，命宫从女命禄位逆行，两套起点要分别写清。
- 检查白虎、天狗是否占一、五、七宫，记录是哪一神占哪一宫。
- 制化必须落到具体的时辰与方位，并写明采用的是麒麟到方、贵人登天时还是麒麟凤凰时。
- 月将的节令界线与排月柱的月建不同，不能互相套用。
- 吉名或吉时的名称本身不等于制化成立，要核到具体的位置与参数。
