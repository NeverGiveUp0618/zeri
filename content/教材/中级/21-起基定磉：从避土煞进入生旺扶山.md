# 第21章 起基定磉：从避土煞进入生旺扶山

> **前置**：先完成第20章；可按目录回看相关基础。

> **本章的一句话**：能识别起基行墙的实际时点，并用正体五行核坐山。

## 一、先把问题讲清楚

动土是整地挖基础，起基定磉则进入房屋方向与结构的正式建立。砖混结构的起基行墙、木结构安石磉、现代框架结构起地圈梁，在原课中分别对应具体动作。学习时用动作定位，不只按施工单位写的“开工”两个字套用。

这个阶段除了避凶，还特别重视旺气与扶山。坐山先取正体五行，再看日课是否生旺相扶；日课格局是否漂亮，要以它对坐山和主命的作用为前提。不能因为四柱同干同支，就跳过它究竟补谁、是否冲山。

起基定磉赋与后面的造宅赋有重合。课程把重复条目通过链接连接，保持每条规则的具体事项条件。你读本章能完成“这是哪一个施工节点、坐山用哪套五行、哪些仍需专查”三项，而不必重复背两篇相似讲稿。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 动土 | 整地、挖基础的阶段 |
| 起基行墙 | 砖石结构正式起砌的节点 |
| 定磉 | 木结构安置石磉等定基节点 |
| 现代对应 | 原课提到地圈梁施工等具体动作 |
| 正体五行 | 亥壬子癸水；寅甲卯乙巽木；巳丙午丁火；申庚酉辛乾金；辰戌丑未艮坤土 |
| 判断重点 | 避忌之外，还要看坐山生旺 |

## 三、实际怎么检查

1. 让施工方说明当天具体做哪一道工序。
2. 确认房屋中线、坐山兼向与实际建立方向的节点。
3. 按正体五行定坐山属性，查生扶与旺相。
4. 再转造宅专章核更完整的山家与日家避忌。

## 四、原课例子与拆解

p350解释定磉是先定石墩、再立木柱；p351说明现代房屋地圈梁等具体施工节点，并列乾山属金、艮山属土、子山属水。读例时先把工程动作和采用五行写清，后面才能讨论这份日课是否扶山。

## 五、易错与适用边界

正体五行的乾属金、艮坤属土，与斗首山五行不同。这里不能用斗首“乾亥火”来代替乾山的正体属性。
