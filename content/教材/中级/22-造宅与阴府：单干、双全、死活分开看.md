# 第22章 造宅与阴府：单干、双全、死活分开看

> **前置**：先完成第21章；可按目录回看相关基础。
> **本章解决什么**：能按成对天干识别双全，并把山运死活留给下一层核验。
> **本章的一句话**：能按成对天干识别双全，并把山运死活留给下一层核验。

## 一、先把问题讲清楚

造宅赋以起基行墙为主要应用节点，系统讲山头三煞、四柱冲山、阴府、消灭、文曲、山运等。原文不是让你见一个煞名便立刻弃课，而是把避、制、轻重与事项条件连起来。学习阴府时，尤其要拆开犯到、单干双全、死活三层。

正阴府由日课天干化气克坐山纳甲化气而起；傍阴府还涉及天干山及三合支等具体关系。正阴府单干可按条件制化，傍阴府单干在相应段落较轻，双全则要更慎。双全不是课里出现两个忌干就成立，而是同一组两个不同的天干都出现。

例如离卦的丁壬组，两个丁仍然只有丁一个字，不能计为丁壬双全；乾、坤又涉及两组分别对应的阴府，不能把不同组各出现一字凑成“双全”。就算真双全，原课还要求分山运死活，不能用一次计数直接代替完整判断。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 甲己组 | 正阴府艮、巽 |
| 乙庚组 | 正阴府乾、兑 |
| 丙辛组 | 正阴府坤、坎 |
| 丁壬组 | 正阴府乾、离 |
| 戊癸组 | 正阴府坤、震 |
| 单干 | 同组只见一个不同干字，重复不增加种类 |
| 双全 | 同一组两个不同干字俱见 |
| 死活 | 另核年化气与山运纳音，见第29章 |

## 三、实际怎么检查

1. 先明确造宅、开山还是局部修方，保留事项语境。
2. 日课天干与坐山纳甲化气对照，确认是哪一组。
3. 对每一组分别去重，看单干或双全，不能跨组合并。
4. 再查山运死活及制化条件，不将双全提示当最终整课结论。

### 手算练习：把同组去重与跨组分别核

先固定午山对应丁壬组：只给丁、丁，去重后是一个丁，为单干重复；给丁、壬，则同组两干齐，为双全。再固定乾山的乙庚组与丁壬组：给乙、丁时，两组各见一干，不能跨组相加为双全；给乙、庚、丁时，乙庚组双全，丁壬组单干。这些只是天干组合练习，没有编造年月日时，更没有完成山运死活判断。

## 四、原课例子与拆解

p1592原例：庚子年、丁亥月、壬寅日、辛丑时，午山子向。午属离，离纳己，丁壬化木克己所属甲己土；课中丁、壬两个字都出现，所以叫双全。原课紧接着说只出现丁或壬一个字为单干，并继续分死活。这是纠正原分析器计数错误的直接依据。
