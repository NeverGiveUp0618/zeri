# 第22章 造宅与阴府：单干、双全、死活分开看

> **前置**：先学 [第2章](#zr-02)、[第9章](#zr-09)、[第21章](#zr-21)。
> **本章解决什么**：能按成对天干识别双全，并把山运死活留给下一层核验。
> **本章的一句话**：阴府按具体山和同组天干核，单双与死活分层判断。

## 一、先把问题讲清楚

造宅碎金赋与起基行墙共用，是在起基行墙的基础上进一步选择（PDF第364页）。它包含山头三煞、四柱冲山、阴府、消灭、文曲、山运等多类神煞。学习时不宜见一个煞名就弃课，而要把“是否犯到”“犯到之后怎样轻重”“能否制化”三件事分开。

阴府这一项最容易混乱，要拆成三层：一是犯不犯，二是单干还是双全，三是活阴府还是死阴府。

正阴府的来源是天干化气克坐山的纳甲化气；傍阴府则是天干对天干，并包括三合的支（PDF第1591页）。同一个具体的山，要先查它属于哪一种阴府，再看对应的天干组。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 甲己组 | 正阴府为艮、巽 |
| 乙庚组 | 正阴府为乾、兑 |
| 丙辛组 | 正阴府为坎、坤 |
| 丁壬组 | 正阴府为乾、离 |
| 戊癸组 | 正阴府为坤、震 |
| 单干 | 同一组内只见一个不同干字，重复不增加种类 |
| 双全 | 同一组两个不同干字俱见 |
| 正阴府的制化 | 单干制化可用，双全先作忌项，仍须续核死活 |
| 傍阴府的制化 | 单干不忌、可不须制化；双全先作忌项，仍须续核死活 |
| 活阴府 | 年化气五行与山运纳音五行相同，为活阴府，为吉 |
| 死阴府 | 年化气五行与山运纳音五行不同，为死阴府，为凶 |
| 死活的推算 | 见[第29章](#zr-29) |

### 八卦原理不能整卦套到三座山

上表是八卦纳甲的原理。具体到某一座山，要以该山的正阴府、傍阴府为准。如艮山的正阴府为甲、己二干，寅山的傍阴府为丁、壬二干，丑山的傍阴府为乙、庚二干（PDF第1604至1607页）。同属艮卦，三山各有不同的阴府组，不能一律处理。

## 三、实际怎么检查

1. 先明确事项是造宅、开山，还是局部修方；阴府只用于开山动土，只论坐山，不论向上（PDF第1591页）。
2. 日课天干与坐山纳甲化气对照，确认犯的是哪一组。
3. 对每一组分别去重，判断单干或双全，不能跨组合并。
4. 若是单干，正阴府可按化气五行制化；若双全，先记为忌项，继续核死活，不到此直接作最终结论。
5. 再查年化气与山运纳音，判断活、死，不以一次计数代替完整判断。

### 手算练习：同组去重与跨组分开

先看午山。午属离卦，离纳己，所以午山的正阴府在丁壬组（PDF第1591页）。若课中只有丁、丁，去重后仍是一个丁，为丁壬组的单干；若课中有丁、壬，两者都在，为双全。

再看乾山。乾山的正阴府同时涉及乙庚组和丁壬组。若课中只见乙与丁，两组各见一干，不能把乙、丁相加成双全；若课中见乙、庚、丁，则乙庚组双全，丁壬组为单干。每组都要独立核对。

## 四、原课例子与拆解

PDF第1592页给出一个原例：庚子年、丁亥月、壬寅日、辛丑时，午山子向。只论午山，午为离卦，离纳己，化气属土；日课中丁壬合化木，木克己土，课中丁、壬两个字都出现，所以叫双全（PDF第1592页）。

同页又说，课中只出现丁或壬一个字的，叫单干，单干可制化。双全之后仍要分死活：活阴府即使双干也可用，死阴府不能用。

## 五、易错与适用边界

- 双全不是课里出现两个忌干就成立。两个字必须是同一组的两个不同干字。
- 单干在正阴府可制化，在傍阴府原文说“不须制化”，两者的处理不同（PDF第1592页）。
- 死阴府的处置，资料两说，需待核。PDF第382页说：“活阴府不用制化。死阴府需要制化，用化气五行来制化”；PDF第1592页却说：“死阴府不能用。”课程并列两说，不替读者选。
- 阴府的死活需要年化气与山运纳音，若题目没有给出，只能判断到双全或单干，不能判断死活。
- 造宅还有山头三煞、文曲、消灭等专条，阴府一项不能代替全部核查。

## 七、本章小结

- 阴府先查具体山的正阴府或傍阴府，再对应天干组。
- 同组去重，跨组分开；单干与双全的判断只在同一组内成立。
- 正阴府单干可制化，傍阴府单干不须制化；双全仍须核死活，第1592页明确活阴府双干也可用。
- 活阴府与死阴府的处置，原文两说并列，待核。
- 死活需要年化气与山运纳音，留给下一层核验。
