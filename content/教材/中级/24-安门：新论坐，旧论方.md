# 第24章 安门：新论坐，旧论方

> **本章的一句话**：能按新旧、门的性质、实际门位选择参数。

## 一、先把问题讲清楚

安门先问是哪一种门。原课特别重视收外山外水的外门和门楼，普通装修中室内卧室、厨房门另有语境。门位、门向、房屋坐山分别记录，不能用门扇朝向代替门所在方位。

新造安装堂屋正门、侧门，在原课核心段落按房屋坐山论；旧房建好后重新在向上开门，以向这个实际方位论；旧房在侧方开门，则以全屋立极所得的门位论。新旧区分与动作对象是本章的关键，不能只背“安门论向”。

门楼又涉及院落和独立构筑物，不应将房屋大门的一个例子推广到所有门楼。遇同册其他段落对门楼的表述不一致，要注明具体对象，保留现场参数，而不是为了让软件只留一个选项就删掉条件。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 门位 | 门相对房屋或院落立极点的位置 |
| 门向 | 门的朝向，与门位不同 |
| 新造堂屋门 | 依p426以房屋坐山论 |
| 旧屋向上开门 | 取实际向方 |
| 旧屋旁门 | 取实际门位之方 |
| 门楼 | 单列对象，查原课具体施工与方位语境 |

## 三、实际怎么检查

1. 区分外门、室内门、院门或门楼。
2. 记录新造还是旧屋改门，说明正在做什么动作。
3. 确定立极点，分别记坐山、门位和门向。
4. 按专条选参数，再查该方或山的年月日时避忌。

## 四、原课例子与拆解

p426连续三个原例：新造子山午向安大门，以子论；旧屋在向上重新开门，以午论；旧屋开巽方旁门，以巽论。这三个例子足以说明“先看动作再选参数”，无需编一个新日课去证明。

## 五、易错与适用边界

同一个子山午向住宅，旧屋开巽门不能还拿子山替代。p334等概述段落对门楼另有说法，课程不把“新论坐”写成一切新门楼的无条件规则。
