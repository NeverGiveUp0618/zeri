# 第26章 补龙扶山：月令、局与龙力条件

> **前置**：先学 [第3章](#zr-03)、[第5章](#zr-05)、[第9章](#zr-09)。
> **本章解决什么**：能分开补龙、扶山和相主，不把财局次吉当成一概可用。
> **本章的一句话**：补入首、看月令，局的适用还受齐字和龙力条件约束。

## 一、先把问题讲清楚

补龙看入首，不论远龙；扶山看坐山。入首明显的地形先核入首龙，城市平洋等入首不明显时，原课更侧重扶山。不能为凑齐“补龙扶山相主”三个词，就给没有实测的来龙填一个字。

原课多用地支补龙，重视月令。三合、三会、临官帝旺、干支一气等各有自己的齐字条件。三合用于补局有时允许两字，但三会须三字全见；这不能反过来放宽回头贡煞的三字全条件。同一个“三合”名词，出现在不同规则中，门槛要分别记。

生扶也不能只背相生同类为吉。原课在某些龙局中允许财局，前提还看龙力、带煞或耗龙的需要，且称次吉；龙力不足不能照抄。这里保留条件，不把“我克为财”迁移成所有龙山一概喜财。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 补龙 | 只论入首，主看月令，多用地支 |
| 扶山 | 按坐山正体五行核生旺 |
| 三合补局 | 按原课具体条件，有二字与三字层次 |
| 三会补局 | 要求三字全见 |
| 旺局 | 同龙五行的补旺局 |
| 印局 | 生龙的五行局 |
| 财局 | 按龙力及原课条件论，不作普遍首选 |

### 五种补法的成立条件

1. 三合：以三合月取格时，月令要在所取局内；另有临官月配年日时成三合的复合例，见第四节，不能把两种取法混成“所有补法的月支都必须入三合”。两字可以，三字更全。长生、帝旺、墓库月分别说明，不必全等同。
2. 三会：木寅卯辰、火巳午未、金申酉戌、水亥子丑，须三字齐；土龙在此段按水局处理。
3. 干支一气：可以同干或同支成格，采用长生、帝旺等，四墓不照此用。
4. 临官帝旺：例如卯龙用寅卯组合，属于官旺局，不必硬称三合三会。
5. 纳音：第1155页介绍七十二穿山与五虎遁两种说法，但认为测细到穿山格不切实际、纳音补龙价值有限；第1417页又允许水山用纳音水补。资料两说，保留测量条件与后期用法，不合成同一种已经定论的方法。

阳龙阳课、阴龙阴课在第1152至1153页有列，但该段自己又说采用不多、不必过分拘执，不能把它升级成所有局的必要条件。

## 三、实际怎么检查

1. 区分实测入首龙和坐山，缺入首则如实注明。
2. 以月令看龙山旺衰，再列日课地支所成局。
3. 按各补法核齐字条件，不借别条规则凑局。
4. 比较生扶和耗泄，财局另核龙力条件，最后再核主命与诸忌。

### 手算练习：同一火龙比较三种局

按火龙这一个明确对象：寅午戌火与龙同类，为旺局；亥卯未木生火，为印局；巳酉丑金受火克，为财局。演算先立火龙，再写五行作用方向。财局的名称只说明火克金，不自动满足可用条件；还要看龙力及原课所说的耗龙需要。换成其他龙时重新立坐标，不把本例喜忌不加条件地迁过去。

## 四、原课例子与拆解

第1152页子龙例为甲申年戊辰月庚子日丙子时：月令辰进入申子辰局，同时是水墓，称三合墓库格；改用该页另一例甲申年乙亥月庚子日庚辰时，则亥临官、课支又有申子辰，称三合临官格。先辨月令，再辨课中组合，不能见三合二字便省去月令条件。

第1153页庚龙例写己丑年癸酉月丁巳日甲子时，地支虽齐巳酉丑，丁日子时按五鼠遁却应庚子。可学习月令酉与金局的结构，原时柱不作为核实可用课。

PDF第1155至1156页以木龙、火龙分列旺局、印局、财局与煞泄局；火龙以寅午戌为三合旺局、亥卯未为印局、巳酉丑为财局次吉。紧接着答疑提醒，财局终究有耗，龙力不足不能用。这个例子支持的是有条件比较，不支持“财局都是上吉”。

## 五、易错与适用边界

- 土龙在本段特定按水局处理，不由普通土克水关系反改表内旺局。
- 第1417页木龙段将临官写亥、申子辰写旺局，与第1156页临官寅、申子辰印局不同。资料两说，本章表列完整较早段，并在此保留后期异文。
- 第1416页操作说法将补龙扶山合论、以坐山为主，第1151至1152页则区分实测入首与坐山。现场入首明显时不能因为后期简法就伪造或删除实测记录。
- 扶山除日课相合，还要吉星到山、无大凶煞占据。月令有助不代表三煞、岁破、阴府等已经通过。
- 偏离优先季节时，第1417页允许年日时成局补助；这是组合条件，不是任意月份都免查旺衰。

## 七、本章小结

- 入首与坐山分开记录，是否合论注明所采用的段落。
- 月令先定力量，再分别核三合、三会与官旺局的齐字条件。
- 旺、印、财、泄、杀先立龙的五行参照，不背固定吉凶名。
- 财局核龙力，四墓不直接套干支一气，纳音保留两种用法。
- 五行补助之后，继续核实际到山吉神与三煞岁破等专忌。
