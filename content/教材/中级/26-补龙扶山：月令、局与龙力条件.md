# 第26章 补龙扶山：月令、局与龙力条件

> **前置**：先完成第25章；可按目录回看相关基础。
> **本章解决什么**：能分开补龙、扶山和相主，不把财局次吉当成一概可用。
> **本章的一句话**：能分开补龙、扶山和相主，不把财局次吉当成一概可用。

## 一、先把问题讲清楚

补龙看入首，不论远龙；扶山看坐山。入首明显的地形先核入首龙，城市平洋等入首不明显时，原课更侧重扶山。不能为凑齐“补龙扶山相主”三个词，就给没有实测的来龙填一个字。

原课多用地支补龙，重视月令。三合、三会、临官帝旺、干支一气等各有自己的齐字条件。三合用于补局有时允许两字，但三会须三字全见；这不能反过来放宽回头贡煞的三字全条件。同一个“三合”名词，出现在不同规则中，门槛要分别记。

生扶也不能只背相生同类为吉。原课在某些龙局中允许财局，前提还看龙力、带煞或耗龙的需要，且称次吉；龙力不足不能照抄。这里保留条件，不把“我克为财”迁移成所有龙山一概喜财。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 补龙 | 只论入首，主看月令，多用地支 |
| 扶山 | 按坐山正体五行核生旺 |
| 三合补局 | 按原课具体条件，有二字与三字层次 |
| 三会补局 | 要求三字全见 |
| 旺局 | 同龙五行的补旺局 |
| 印局 | 生龙的五行局 |
| 财局 | 按龙力及原课条件论，不作普遍首选 |

## 三、实际怎么检查

1. 区分实测入首龙和坐山，缺入首则如实注明。
2. 以月令看龙山旺衰，再列日课地支所成局。
3. 按各补法核齐字条件，不借别条规则凑局。
4. 比较生扶和耗泄，财局另核龙力条件，最后再核主命与诸忌。

### 手算练习：同一火龙比较三种局

按火龙这一个明确对象：寅午戌火与龙同类，为旺局；亥卯未木生火，为印局；巳酉丑金受火克，为财局。演算先立火龙，再写五行作用方向。财局的名称只说明火克金，不自动满足可用条件；还要看龙力及原课所说的耗龙需要。换成其他龙时重新立坐标，不把本例喜忌不加条件地迁过去。

## 四、原课例子与拆解

p1155–1156以木龙、火龙分列旺局、印局、财局与煞泄局；火龙以寅午戌为三合旺局、亥卯未为印局、巳酉丑为财局次吉。紧接着答疑提醒，财局终究有耗，龙力不足不能用。这个例子支持的是有条件比较，不支持“财局都是上吉”。

## 五、易错与适用边界

教材土龙条目有特定“以水局论”的处理，不能由普通土克水自行改写。四墓干支一气等限制也应保留。任何示意局都必须再过历法，不能为了格局编一套不存在的日课。
