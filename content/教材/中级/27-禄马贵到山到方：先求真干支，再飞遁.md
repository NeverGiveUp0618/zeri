# 第27章 禄马贵到山到方：先求真干支，再飞遁

## 一、先把问题讲清楚

课中见禄马贵，与禄马贵飞到某方，是两个层次。前者先查命课关系，后者还要按年、月等入中飞遁，明确落宫。不能因为日课里有寅，就说甲命真禄已经到所修方。

“真”一般要求完整干支。甲命禄在寅，甲年五虎遁得丙寅，丙寅才是所举真禄；贵人丑未还要配成丁丑辛未。把真干支确定以后，再按原法入中推到山向或修方。每一步都写出来，才查得出是查禄错、配干错，还是飞宫错。

原资料的到方表中大量内容靠图呈现，表格方向和跨旬处理容易被文本提取压乱。本章用清楚的原例教核验，完整算法与图表分开保留；不能把黑箱结果当作你已经掌握了飞遁。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 堆禄堆贵 | 主命干在日课支见禄贵 |
| 进禄进贵 | 主命支在日课干反查 |
| 真禄贵 | 地支再配本命五虎遁所得完整干支 |
| 飞遁到方 | 确定入中参数和飞行规则后，求落宫 |
| 四维禄马贵 | 原课特定项目乾亥、坤申、艮寅、巽巳同推 |
| 使用边界 | 此处归并不推广为所有三煞兼向的规则 |

## 三、实际怎么检查

1. 先定命、山或龙作为起算对象。
2. 查禄贵马地支，再用对应五虎遁配真干支。
3. 写清本次用太岁、月建或哪项参数入中。
4. 逐步推落宫并回原例核对，再查是否冲命冲山。

### 手算练习：先把真干支算出来，再谈到方

以甲年命为局部练习：禄支寅、贵人支丑未先查出来，再由甲己年丙寅起遁。寅是丙寅，未是辛未，丑为丁丑；到此得真禄与真贵的完整干支，但并未指定某年太岁或某月月建入中，所以到方仍未算。把这两个层次分开写，就不会把“真禄丙寅”错当成一个永远固定的东方。

## 四、原课例子与拆解

p1165例甲子年命：禄寅配丙寅，贵丑未配丁丑辛未；乙丑年修方，以乙丑太岁入中再遁到具体方。p1173以辛巳命真禄丁酉，在乙未年飞到兑七；p1174换己亥年后落宫改变。相同真禄，年份变化后到方不能沿用。

## 五、易错与适用边界

p1165对禄马贵允许四维与邻支同推，不等于p365的四维山三煞也能这样简化。原稿个别“寅为禄马”是概称，甲子命的禄与马虽同在寅，其他命不能套用。
