# 第27章 禄马贵到山到方：先求真干支，再飞遁

> **前置**：先学 [第4章](#zr-04)、[第10章](#zr-10)、[第26章](#zr-26)。
> **本章解决什么**：能区分堆进、真禄贵和飞到山方，写出推算中间步骤。
> **本章的一句话**：先求真禄贵干支，再指定入中参数求落宫。

## 一、先把问题讲清楚

课中见禄马贵，与禄马贵飞到某方，是两个层次。前者先查命课关系，后者还要按年、月等入中飞遁，明确落宫。不能因为日课里有寅，就说甲命真禄已经到所修方。

“真”一般要求完整干支。甲命禄在寅，按本人出生年干甲起五虎遁得丙寅，丙寅才是所举真禄；贵人丑未还要配成丁丑辛未。把真干支确定以后，再按原法入中推到山向或修方。每一步都写出来，才查得出是查禄错、配干错，还是飞宫错。

原资料的到方表中大量内容靠图呈现，表格方向和跨旬处理容易被文本提取压乱。本章用清楚的原例教核验，完整算法与图表分开保留；不能把黑箱结果当作你已经掌握了飞遁。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 堆禄堆贵 | 主命干在日课支见禄贵 |
| 进禄进贵 | 主命支在日课干反查 |
| 真禄贵 | 地支再配本命五虎遁所得完整干支 |
| 飞遁到方 | 确定入中参数和飞行规则后，求落宫 |
| 四维禄马贵 | 原课特定项目乾亥、坤申、艮寅、巽巳同推 |
| 使用边界 | 此处归并不推广为所有三煞兼向的规则 |

### 年太岁入中的顺行手算法

以下只展开PDF第1165至1167页明确讲的“当年太岁入中顺行”这一年层方法，不扩展到月、日、时的冬夏至顺逆。

九宫按数序循环：中五、乾六、兑七、艮八、离九、坎一、坤二、震三、巽四，再回中五。这里“当年”是准备修造等用事的年份，不是本人出生年，也不是打开教材时的当前年份。把该用事年份的完整干支放中五，六十甲子每向后走一位，宫位也顺行一步，走到所求真禄贵干支时读落宫。起始太岁占中五，不是从乾六开始。

甲子命在乙丑年：乙丑中五，下一位丙寅到乾六；真贵辛未从乙丑再顺六步到坤二；丁丑从乙丑顺十二步到艮八。三个结果都与PDF第1165至1167页原例相合。

辛巳命真禄丁酉在乙未年：乙未中五、丙申乾六、丁酉兑七，合PDF第1173页。换己亥年时，须沿六十甲子继续顺走到丁酉，不能把相差两干支简单倒退两宫；原例PDF第1174页结果为离九。超过多旬的取用强弱另按原课，不因算法可算就视为首选。

PDF第1167至1168页另明确速查表的第一数用于年干支以及冬至后月日时，第二数用于夏至后月日时；月日时不直接照抄本节年层顺行例。

### 飞天禄不等于飞禄到方

第1186页的飞天禄又称冲禄、倒冲禄：甲禄寅未出现，而课中见申，以申冲寅来说明该关系。飞禄到方则先求丙寅，再用指定干支入中求落宫；前者是课支关系，后者是排宫计算，同有“飞”字也不能合并。

贵人也有堆、进、拱、遥、冲等关系。第1425页辛命见丑卯夹寅为三会拱贵，壬命见亥未缺卯为三合拱贵；甲命见亥卯遥未、乙命见午冲子，又各有起点。壬子命遇乙巳课柱时，壬见巳为贵、乙见子也为贵，两个方向互见才称罗纹交贵。

### 命贵、岁贵与表格使用顺序

命贵由本人出生年干配出，岁贵由当年年干配出。第1425至1426页的“太岁入中寻命贵，月建入中寻岁贵”，规定了两个不同的入中参数，不能同时都用太岁来算。

例为乙巳年己丑月、丙午命：岁贵戊子甲申，命贵己亥丁酉。太岁乙巳入中，命贵丁酉到震、己亥到中；己丑月建入中，岁贵戊子到坎、甲申到乾，未同宫。换戊子月，岁贵戊子到中、甲申到兑，也要重新比较。该例认为跨五旬偏远，一般三四旬以内、二三旬更好，这是取用偏好，不改变先配柱再排宫的步骤。

速查表的数字1至9分别为坎、坤、震、巽、中、乾、兑、艮、离。第1167至1168页说明：第一数用于年干支及冬至后月日时，第二数用于夏至后月日时；入中位先找该列的“中”，再横竖找禄贵交点，某一前后关系还须向上逆数第四格，起点算第一格。不要把格内两个数字读成第73宫，也不要省去原表规定的跨旬处理。

## 三、实际怎么检查

1. 先定命、山或龙作为起算对象。
2. 查禄贵马地支，再用对应五虎遁配真干支。
3. 写清本次用太岁、月建或哪项参数入中。
4. 逐步推落宫并回原例核对，再查是否冲命冲山。

### 手算练习：先把真干支算出来，再谈到方

以甲年命为局部练习：禄支寅、贵人支丑未先查出来，再由甲己年丙寅起遁。寅是丙寅，未是辛未，丑为丁丑；到此得真禄与真贵的完整干支，但并未指定某年太岁或某月月建入中，所以到方仍未算。把这两个层次分开写，就不会把“真禄丙寅”错当成一个永远固定的东方。

## 四、原课例子与拆解

PDF第1165页例甲子年命：禄寅配丙寅，贵丑未配丁丑辛未；乙丑年修方，以乙丑太岁入中再遁到具体方。PDF第1173页以辛巳命真禄丁酉，在乙未年飞到兑七；PDF第1174页换己亥年后落宫改变。相同真禄，年份变化后到方不能沿用。

## 五、易错与适用边界

- 第1165页对禄马贵允许乾亥、坤申、艮寅、巽巳同推，不等于三煞也按这套双山归并；长生印绶又用乾庚、坤戊、艮己、巽乙，不能把两组替代关系混为一张表。
- 甲子命禄与马同在寅，不代表所有命的禄马同支。马为三合长生的对冲、病地，须依命支另查；禄贵为重，马为辅，冲命冲山时不能只追马星。
- 第1164至1166页的本命四煞还附甲乙庚辛或丙丁壬癸山向的组合条件；它与第250至251页一般命煞权用的口径并列，不能抹掉山向限制后合成全情形通则。
- 年月冲与日时冲的轻重不同，但天克地冲在第1165页要求四柱皆慎，不能套“年月轻”免查。
- 速查表的冬夏两数与年层顺行例分开。第1629至1630页为原图速查入口，当前文字层为空，不能声称已据文字恢复全部表格。

## 七、本章小结

- 先分课中见禄、真干支和排宫到方三个层次。
- 命贵取本人年干，岁贵取当年年干，分别写入中参数。
- 年层从太岁中五顺行，不把跨旬差值随便倒退。
- 查表保留冬夏两数及向上第四格步骤，不照抄年层到月日时。
- 四维替代、马星冲命与到向条件按本条范围核，不跨规则套用。
