# 第28章 造命格局：先合龙山命，再谈整齐好看

> **前置**：先学 [第3章](#zr-03)、[第4章](#zr-04)、[第17章](#zr-17)、[第26章](#zr-26)。
> **本章解决什么**：能分清日课日干、龙山十神和事主年干三个坐标。
> **本章的一句话**：格局要对龙山命有作用，整齐的字还须通过历法。

## 一、先把问题讲清楚

造命是选择一份日课来扶助龙、山和主命，不是给当事人重新编造出生八字。原课既讨论日课本身以日承载年月时，也讨论以龙山为我或以事主年干为我的十神。三个坐标都可能出现，必须写清正在分析哪一个。

同样四个相同天干，既可能构成比肩扶助，也可能成为劫财、官杀或过度克泄。正官宜合，不合时数量条件另论；七杀要核制化；四长生还不能冲年命。格局名只概括已经成立的关系，不能替代成立条件。

教材的四柱示意有些只演示格局而非真实历法日课。课程保留它们说明关系，但明确不把四干整齐、四支整齐自动当成某天真的存在。用于实选之前，五虎遁、五鼠遁、实际历日都要复核。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 日课日干 | 分析日课自身日元承载与旺衰 |
| 龙山坐标 | 龙山正体五行与日课的生克十神 |
| 主事坐标 | 出生年干与日课天干的十神 |
| 合官 | 既为官，又有天干相合，不能只取其一 |
| 四长生 | 还须核不冲主命年支 |
| 复核 | 格局与龙山命相关，并通过实际历法 |

### 同字换坐标，十神就变

甲以甲为我，是比肩；同一个甲改以乙命年干为我，就是劫财。分析表必须先写坐标，再标十神，不能只给天干贴一个永久标签。本例只演算明确的同我阴阳关系，不对未给出的完整日课判吉凶。

### 先分相主对象，再看格局

第1161至1162页阳宅以宅主、主妇为主，少主众主为辅；阴宅以仙命为主，祭主次之，众主再其次。出生年柱是人的参照，不用卒年或日课日干代替；破土仙命免论等特殊动作仍按第25章，不能被此总纲覆盖。

| 格局或关系 | 本章保留的数量与条件 |
|---|---|
| 印绶 | 宜正印；偏印一二处与多见不同，另核泄制 |
| 比肩 | 同干可成格，己命四己为例；本日回避与古例喜比肩有两说 |
| 劫财 | 以年命为我辨同类异性，不将山家比劫可助移作主命皆吉 |
| 四长生 | 如壬见申、丙戊见寅，仍须不冲主命年支 |
| 合官 | 同时是正官且天干相合；不合之官宜少，一二处与多见不同 |
| 七杀 | 第1162页一位可食神制、二位重忌；第1432页又列一二位印化或食制，两说分记 |
| 财格 | 财喜合，甲命四己为合财；正偏财仍核数量、龙山是否得补 |
| 禄马贵 | 堆进、真干支与到方分层，马不能冲本命 |
| 三德丛集 | 指天德月德岁德同到，再合扶补格局，不凭名称代替定位 |
| 双飞蝴蝶 | 仅两组柱或两阳两阴的结构，仍要过月时配干与历日 |

日课本身又有年月日时的分工：年先查大项，月令定旺衰，日承载年月，时辅助日。第1200页要求日干有气，但这不改变分析事主时以出生年干为我；三个坐标必须分栏写。

### 龙山十神与主命十神同定义，不同对象

以壬、子阳水为龙山时，戊七杀、己正官，丙偏财、丁正财，庚偏印、辛正印，甲食神、乙伤官，壬比肩、癸劫财。换成癸阴水，上述正偏与食伤比劫按阴阳互换。第1201至1204页各类关系都是先比五行生克，再分同性异性，不能给某个天干贴永久的十神标签。

第1203页说龙山比劫可相助，主命劫财段则偏忌，适用对象不同，不删掉其中一条来凑一致。第1202页“丁山壬日丁壬合财”的注语又与丁火所克为金的定义不合；丁见壬应先按官合关系核，保留该句名词疑点，不将它拿来教合财计算。

### 三德的月表

本段三德月表取候选用事年份和用事月份；这与前面按人物出生年干定十神的表分开。天德按第1435页逐月为丁、申、壬、辛、亥、甲、癸、寅、丙、乙、巳、庚。其起法是在二十四山上，从月建数十位：孟仲月顺行、季月逆行，遇四维再进一位；不是只在十二支里数十。月德按月支三合局取阳干，寅午戌丙、巳酉丑庚、申子辰壬、亥卯未甲。

该页三德丛集列甲己年未月在甲、乙庚年丑月在庚、丙辛年戌月在丙、丁壬年辰月在壬；未列出的年组不能自行补造一个同聚月份。天德合、月德合、岁德合在此列为较轻的助益，仍与本星分开。

## 三、实际怎么检查

1. 在分析栏顶写明当前十神坐标。
2. 看每一柱对该坐标的生克与数量，而不是先套格局名。
3. 核官杀制化、长生冲命等专门条件。
4. 最后校验实际日期与四柱对应，示意课不直接变成可用课。

## 四、原课例子与拆解

换坐标练习：甲以甲为我叫比肩；乙命以乙为我，见同一个甲则是劫财。依据第1204页定义，先立“我”，再定名称，不因两字都属木就一概叫比肩。

第1438页庚申年壬午月庚申日壬午时，年月与日时两组重复，属于所举双飞蝴蝶；另例癸亥年癸亥月甲子日甲子时为两阴两阳、两组相同。两例的五虎遁和五鼠遁相容，但原页没有给出可复查的公历日期，不能补造使用结果。

PDF第1162至1163页举乙命见庚为合官，既是正官又有乙庚合；乙命见辛则为七杀，不可因同属金就当作同样的官格。PDF第1438页有双飞蝴蝶等示意结构，学习格局时仍须核年月日时能否实际并存。

## 五、易错与适用边界

“有合官星宜多”和“不合正官不宜多”并非同一句话的矛盾，条件就是是否合。本章明确以月令论日课生旺，不借其他课程的取舍覆盖。

第1432页印绶例将乙亥、乙未都写成月柱，是一个字段字误；它不能读成一份日课有两个不同月柱。学习时先核年月日时四字段，再分析印星，未核实的原写法不直接当可用课。

## 七、本章小结

- 每张十神分析表先标日干、龙山或主命年干是哪一个“我”。
- 阳宅、阴宅分别确定主要人物，特殊动作按专章处理。
- 官财看是否合、是否过多，七杀及偏印看具体制化条件。
- 相同结构先过历法，原例没给公历和反馈就保持缺项。
- 三德和禄马贵都核实际到位，不用格局名称取代逐项判断。
