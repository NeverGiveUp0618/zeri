# 第28章 造命格局：先合龙山命，再谈整齐好看

> **前置**：先学 [第3章](#zr-03)、[第4章](#zr-04)、[第17章](#zr-17)、[第26章](#zr-26)。
> **本章解决什么**：能分清日课日干、龙山十神和事主年干三个坐标。
> **本章的一句话**：格局要对龙山命有作用，整齐的字还须通过历法。

## 一、先把问题讲清楚

造命是选择一份日课来扶助龙、山和主命，不是给当事人重新编造出生八字。原课既讨论日课本身以日承载年月时，也讨论以龙山为我或以事主年干为我的十神。三个坐标都可能出现，必须写清正在分析哪一个。

同样四个相同天干，既可能构成比肩扶助，也可能成为劫财、官杀或过度克泄。正官宜合，不合时数量条件另论；七杀要核制化；四长生还不能冲年命。格局名只概括已经成立的关系，不能替代成立条件。

教材的四柱示意有些只演示格局而非真实历法日课。课程保留它们说明关系，但明确不把四干整齐、四支整齐自动当成某天真的存在。用于实选之前，五虎遁、五鼠遁、实际历日都要复核。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 日课日干 | 分析日课自身日元承载与旺衰 |
| 龙山坐标 | 龙山正体五行与日课的生克十神 |
| 主事坐标 | 出生年干与日课天干的十神 |
| 合官 | 既为官，又有天干相合，不能只取其一 |
| 四长生 | 还须核不冲主命年支 |
| 复核 | 格局与龙山命相关，并通过实际历法 |

### 同字换坐标，十神就变

甲以甲为我，是比肩；同一个甲改以乙命年干为我，就是劫财。分析表必须先写坐标，再标十神，不能只给天干贴一个永久标签。本例只演算明确的同我阴阳关系，不对未给出的完整日课判吉凶。

## 三、实际怎么检查

1. 在分析栏顶写明当前十神坐标。
2. 看每一柱对该坐标的生克与数量，而不是先套格局名。
3. 核官杀制化、长生冲命等专门条件。
4. 最后校验实际日期与四柱对应，示意课不直接变成可用课。

## 四、原课例子与拆解

p1162–1163举乙命见庚为合官，既是正官又有乙庚合；乙命见辛则为七杀，不可因同属金就当作同样的官格。p1438有双飞蝴蝶等示意结构，学习格局时仍须核年月日时能否实际并存。

## 五、易错与适用边界

“有合官星宜多”和“不合正官不宜多”并非同一句话的矛盾，条件就是是否合。早先八字教材“不论旺衰”的课程立场不能迁入择日，本资料明确以月令论日课生旺。
