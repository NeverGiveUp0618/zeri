# 第3章 月令旺衰、十二长生与纳音

> **前置**：先学 [第2章](#zr-02)。
> **本章解决什么**：会区分月令旺衰和十二长生，知道纳音何时进入判断。
> **本章的一句话**：月令旺衰、十二长生、纳音各有坐标，不能互代。

## 一、先把问题讲清楚

月令旺衰回答某种五行在这个季节有没有力量；十二长生回答某个天干运行到某支时所处的阶段。它们是两张不同的表。不能看到一个“旺”字，就把季节旺相、十二长生帝旺和整课大吉看成一回事。

以春季木当令为例：木旺，木生的火相，生木的水休，克木的金囚，被木克的土死。换月令时，要把参照重新放回当令五行。择日里的扶山、日干得令和斗首旺衰都用得到这个坐标，但具体喜忌还要回各自章节。

十二长生按天干阴阳分顺逆，戊随丙、己随丁。原课有些造葬和斗首段落另谈墓库的用法；特别是阴宅、阳宅对墓库的取舍不同，不能把“墓”统一判成吉或凶。纳音则另按完整干支取，不取单干代替。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 旺 | 与月令同五行 |
| 相 | 月令所生的五行 |
| 休 | 生月令的五行 |
| 囚 | 克月令的五行 |
| 死 | 月令所克的五行 |
| 长生顺逆 | 阳干顺行，阴干逆行；戊随丙，己随丁 |
| 纳音单位 | 按完整干支查询，如甲子乙丑海中金 |

### 十二长生先有起点，才能顺逆推

十二阶段依次为：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。

| 天干 | 长生起支 | 推行 |
|---|---|---|
| 甲 | 亥 | 顺行 |
| 乙 | 午 | 逆行 |
| 丙、戊 | 寅 | 顺行 |
| 丁、己 | 酉 | 逆行 |
| 庚 | 巳 | 顺行 |
| 辛 | 子 | 逆行 |
| 壬 | 申 | 顺行 |
| 癸 | 卯 | 逆行 |

按p847–848，丙从寅起：寅长生、卯沐浴、辰冠带、巳临官、午帝旺；乙从午逆推：午长生、巳沐浴、辰冠带、卯临官、寅帝旺。到此只是求状态，不把状态名称直接当成整课结论。

## 三、实际怎么检查

1. 先标出月支及当令五行。
2. 明确正在判断坐山、日干还是某个斗首用神，不能换对象而不换坐标。
3. 需要十二长生时，先查起点与顺逆，再数到目标支。
4. 需要山运库音时，先推出完整山运干支，再查纳音，不把它与正体五行混算。

## 四、原课例子与拆解

p848给丙从寅起长生、壬从申起长生；并说明戊随丙、己随丁。因而同一地支对不同天干可能是不同阶段。p125则按甲子乙丑、丙寅丁卯等成对列纳音：这是另一套查询表，不能把丙火的长生结论当作丙寅纳音结论。

## 五、易错与适用边界

斗首p1237一段以“木在什么季节”为叙述坐标，与“以当令五行为我”的说法方向不同，读表必须先辨主语。十二长生的阴阳顺逆依择日资料，不借用八字课程里的特殊阴阳表。
