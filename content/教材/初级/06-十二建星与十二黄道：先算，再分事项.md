# 第6章 十二建星与十二黄道：先算，再分事项

> **前置**：先学 [第4章](#zr-04)。
> **本章解决什么**：能推出建星，并识别建日动土和破日的重点避忌。
> **本章的一句话**：月支起建，再按事项看宜忌；建星与黄道值神分开查。

## 一、先把问题讲清楚

十二建星以月支起建，向后依次为除、满、平、定、执、破、危、成、收、开、闭。寅月寅日起建，卯日为除，顺推到申日就是破。建星随节令月改变，不能按公历或农历月份直接套。

原课尤其强调建日和破日：建日与土府相关，动土修造须重点核；破日为月破，重要用事避开，不能只因同时有大吉神就忽略。其他建星还要看具体事项，不能把十二字粗分成一组普遍吉、一组普遍凶。

十二黄道值神与十二建星也不是同一张循环表。青龙、明堂等是值神名，建、除等是建星名。课程中遇到“天德”，还须区分十二值神里的天德与另一个吉神系统中的月家天德，不因同名就把起法和能力合并。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 建 | 月支对应之日；本课重点核土府与动土 |
| 破 | 月支对冲之日；即月破 |
| 开 | 多宜开业出行，安葬要另避 |
| 闭 | 不概括为百事皆凶；原课允许结合其他吉神用于安葬 |
| 六黄道 | 青龙、明堂、金匮、天德、玉堂、司命 |
| 六黑道 | 天刑、朱雀、白虎、天牢、玄武、勾陈 |

### 十二建星逐项查用事

| 建星 | 原课p147–150列出的代表用事与限制 |
|---|---|
| 建 | 裁衣、纳财、交易等；忌动土、乘船、开仓库 |
| 除 | 沐浴、清洁、服药、放水等；忌嫁娶、出行、开井 |
| 满 | 造宅、婚礼、移徙、出行等；忌栽种、开基、放水 |
| 平 | 婚礼、移徙、修道、装修等；忌栽种、开基、放水 |
| 定 | 栽种、造宅、婚礼、移徙、动土、开井等；忌诉讼 |
| 执 | 原页同时列宜造宅与忌修造、搬家，保留原词，具体范围待核 |
| 破 | 重要用事避；原课列捕鱼、拆除等破坏性用途 |
| 危 | 原课仅举酿酒，其他少成就，并提醒不宜登高 |
| 成 | 造宅、婚礼、旅行、动土等；忌诉讼 |
| 收 | 开仓、交易、入学、婚礼、造宅等；忌出行、安葬、针灸 |
| 开 | 学艺、就业、婚礼、出行等；忌安葬 |
| 闭 | 结合其他吉星可用于安葬，不能据此放行其他事项 |

### 十二黄道如何起青龙

依p133–134，正七月起子、二八起寅、三九起辰、四十起午、五十一月起申、六十二月起戌。从起支顺排青龙、明堂、天刑、朱雀、金匮、天德、白虎、玉堂、天牢、玄武、司命、勾陈。

例如亥月属十月，从午起青龙，未明堂、申天刑、酉朱雀、戌金匮、亥天德。这个“亥日天德值神”仍要与其他系统的天德吉神分开读。

## 三、实际怎么检查

1. 先按交节核定月支。
2. 从月支起建，顺数到日支，写出建星名称。
3. 对照当前用事，重点检查建日动土、破日重要用事等限制。
4. 另查值神与其他日家神煞，不能拿黄道替代全部核验。

### 手算练习：同月分别数建与破

固定寅月，从寅支起建：寅建、卯除、辰满、巳平、午定、未执、申破、酉危、戌成、亥收、子开、丑闭。这样能直接看出月支到日支相隔六位的申为破。换亥月时必须从亥重新起建，不能沿用寅月的表。得出建星以后，仍要对照用事；例如寅月子日为开，只能说明这层建星，不等于安葬或动土已经通过。

## 四、原课例子与拆解

p148给乙巳年戊寅月庚申日：寅月从寅起建，数到申为破，所以是月破日。原课说明即使见岁德，也不取作重要用事的通用吉日。p150又说明开日忌安葬，闭日结合其他吉神可用于安葬，显示同一建星必须落到事项上判断。

## 五、易错与适用边界

“开”不能因为字面好听就通用于安葬；“闭”也不能因为字面闭塞就把丧葬用途全删掉。旧知识卡把平、收等粗列凶组，课程以逐事项原文为准。
