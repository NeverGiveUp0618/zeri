# 第9章 冲山四破与山家三煞

> **前置**：先学 [第5章](#zr-05)、[第8章](#zr-08)。
> **本章解决什么**：能分别检查年、月、日、时对山方的影响。
> **本章的一句话**：冲山逐柱核，三煞由时间三合局找方，不漏夹干山。

## 一、先把问题讲清楚

冲山先要有坐山这个对象。年支冲坐山称岁破，月支冲山称月破，日支、时支分别为日破、时破。本章的“月破冲山”与建星里月日相冲的月破要分开写：一个是月对山，一个是月对日，同名不能混成一次检查。

山家三煞按时间支归三合局，再找对应三方。四柱要分别检查，不能只查今年无煞就视日时也无煞。归组时一次取年、月、日、时中的一柱：这柱的支是申、子、辰任一字，就查申子辰这一行，不要求三字同时出现。回头贡煞要求三字全见，是另一规则。方位除了三个地支，还含夹在其间的两个天干山；例如东方寅甲卯乙辰，不能只列寅卯辰而漏甲乙。

新造、全做与修方取对象不同：前者主要看坐山，后者看实际施工方。原课说三煞可向，是在论坐山的语境中；若正好在向方施工，向此时就是动方，仍需按修方核验。

## 二、规则与条件表

| 项目 | 判断与条件 |

| 申子辰时间 | 三煞在巳丙午丁未 |
| 寅午戌时间 | 三煞在亥壬子癸丑 |
| 巳酉丑时间 | 三煞在寅甲卯乙辰 |
| 亥卯未时间 | 三煞在申庚酉辛戌 |
| 年冲坐山 | 岁破 |
| 月日时冲坐山 | 分别称月破、日破、时破 |
| 四维山 | 依原课核兼家，不用单一归支代替 |

### 同一时间局内，三支各有名称

三合局的绝、胎、养三位，分别为劫煞、灾煞、岁煞。因此申子辰时间是巳劫、午灾、未岁；寅午戌时间是亥劫、子灾、丑岁；巳酉丑时间是寅劫、卯灾、辰岁；亥卯未时间是申劫、酉灾、戌岁。夹在三支之间的两干称坐煞，第366页另录丙为伏兵、丁为大祸的说法，不能据名称不同漏掉方位。

太岁与岁破也分开。第214页说新造太岁可坐不可向：坐太岁与坐岁破不是同一件事；局部修方则忌动太岁方。若把“可坐太岁”扩大成“太岁所在方可随便施工”，就抹掉了新造与修方的区别。

## 三、实际怎么检查

1. 先确定是整体造作还是局部修方，选对对象。
2. 按六冲逐柱核对山与年月日时，注明哪一柱犯。
3. 每一柱归三合局，再对照三煞五山，不漏中间两干。
4. 若为四维山，补查兼向；参数不足不能作无煞结论。

### 手算练习：从时间支找三煞五山

给定一个子支时间：先归申子辰水局，再对照三煞在南方巳午未；回到二十四山把中间的丙、丁补列，因此为巳丙午丁未。若只列巳午未，就会漏掉丙山、丁山。这是给定单支的规则演算，尚未提供其余四柱、主命和具体工序，不能凭这一层说整课可用或不可用。遇四维山还须进一步补兼家。

第367页的午年午月遇辰日，提示年、月与日可能分别限制不同方位。不能因年、月对某山有利就删除日上的三煞，也不能只保留限制最少的一柱。（本课归纳）

## 四、原课例子与拆解

PDF第214页给亥山巳向，巳年冲亥而犯岁破；丙午年则子山午向犯岁破。PDF第215页给乙巳年东方寅甲卯乙辰五山为三煞方。若申山寅向没有在向方施工，可与在寅方实际开门的修方分开看；后者动的是三煞方，不能用“可向”放行。

## 五、易错与适用边界

- 日家月破核月支对日支，月破冲山核月支对坐山，不能看过其中一次就省去另一次。
- 山家三煞用时间对空间；主命四煞用时间与出生年命。两个对象不同，不把山家三方五山全套到人命。
- 四维山缺兼家时保留待核。天干山的冲山也不能凭一张地支六冲表直接判完，须看该条的取参照法。
- 向煞在整体坐山语境中较轻；修向时向已成为实际动方，不能再借“可以向”放行。
- 第216页将邻近施工、距离远近、围墙等也列入传统方位判断，并未给出统一的距离数值。可记录邻近动方，不自行编出多少米以内必犯的阈值。

## 六、原文对照

> 冲山在年称为岁破，冲山在月为月破，冲山在日为日破，冲山在时为时破。
>
> 〔《择日合集》PDF第214页〕

## 七、本章小结

- 先判新造全做还是修方，再定坐山或实际动方。
- 冲山分别写哪一柱冲了哪一山，不与日家月破合并。
- 每柱归三合局，列齐劫灾岁三支与夹干两山。
- 四维补兼向，天干山按专条，缺资料继续核。
- “可向”不等于可以在该向方施工，修向另按动方看。
