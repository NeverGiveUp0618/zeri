# 第13章 出行、祈福与祭祀的事项差别

> **前置**：先学 [第4章](#zr-04)、[第8章](#zr-08)、[第10章](#zr-10)。
> **本章解决什么**：能按事项查宜忌，不把固定民俗日期与一般筛日混用。
> **本章的一句话**：祈福、祭祀、出行各查自己的宜忌与实际时点。

## 一、先把问题讲清楚

出行、祈福和祭祀都属于生活用事，但不是同一个宜项。祈福在资料中指祈祷神佛等活动，祭祀主要指祖先祭祀；出行还要看出发时刻与主事命课关系。不能因为一天宜祭祀，就自动推出它宜远行。

原课的祈福五步曲先筛宜祈福，再列五腊、三会、三元等固定日期，之后核日时阴阳配合与相关避忌，最后结合主命。固定宗教、民俗日期有自身约定，不是从当日黄历宜项推出来的。

这类用事先把动作说清楚：出发、开始仪式、一般上香、修坟动土，所需核验不同。清明期间一般扫墓与大规模修坟也不能混同；一旦动作变成破土修造，应回到对应专章，而不是继续套一般祭祀条件。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 祈福 | 先查宜祈福，再依本项日时避忌 |
| 祭祀 | 祖先祭祀，不与一般出行宜项混用 |
| 出行 | 查宜出行和实际出发时点，结合主命 |
| 五腊 | 正月初一、五月初五、七月初七、十月初一、腊月初八 |
| 动作变化 | 涉及破土修坟则转入修造、安葬相关核验 |

### 固定日期与日时条件

五腊分别是天腊正月初一、地腊五月初五、道德腊七月初七、民岁腊十月初一、王侯腊腊月初八。三会的日期为正月初七、七月初七、十月十五；所列原页仅提到三元名目，没有列齐三元日期，本章不借外部版本补表。

一般祈福按第229至230页五步走：筛宜祈福；另记固定仪式日期；阳日配阴时、阴日配阳时；避建、破、四废、禄空、戊日及截路空亡时；最后核主事刑冲害与禄马贵。阴阳按甲丙戊庚壬阳、乙丁己辛癸阴，落到时干后仍须合五鼠遁。戊日的宗教禁忌尤其重戊辰、戊戌，不直接移成全部动土不可用。

### 截路空亡按时算，并有四项例外

第231页以日干起五鼠遁，遇壬癸时为检查入口。它是时辰概念，与六甲旬空不同，也没有由本条推出的“截路空亡日”；进表、出行、建醮是其主要限制，用到嫁娶、竖造、安葬又须分范围看。

第232页补四项不空：日时同支；日干贵人时；与日支三合的时；时柱纳音属木。戊申日从壬子起，十二时中壬子、癸丑、壬戌、癸亥皆见壬癸，但子与申三合、丑为戊贵，且壬子癸丑纳音木，故该例最后只取戌亥为截路空亡。不能只看到“壬癸”两字就抹掉这些条件。

### 出行的日忌与俗忌分开

| 层次 | 第234至235页的检查内容 |
|---|---|
| 吉项 | 天月德及合、天恩、月财、驿马、三五六合、四相；满成开及本命禄马贵 |
| 日忌 | 四离四绝、往亡、气往亡；无禄也限制出行求财 |
| 时忌 | 截路空亡；冲日支及五不遇时另查 |
| 四顺 | 建与寅宜行，成与卯宜归，属于所列习俗 |
| 四逆 | 申不行、酉不离，七不出、八不归，原页允许按地方习俗取舍 |
| 五不归 | 己卯、己酉、辛巳、辛酉、辛亥、丙申、丙辰、丙戌、壬子、壬辰、庚申 |
| 大退 | 年月日时各论，原页说年重时轻；出行条目又列午后大退时可不忌 |

四顺、四逆、五不归在该段都归俗忌，资料允许依当地是否讲究取舍；它们与四离四绝、往亡等日时专忌分栏记录。

气往亡按节气后日数列：立春7、惊蛰14、清明21；立夏8、芒种16、小暑24；立秋9、白露18、寒露27；立冬10、大雪20、小寒30。它与按干支月查的往亡是两种表；原页未交代交节当天如何计入日数，临界日期须按具体历表核，不自行补算法。

## 三、实际怎么检查

1. 分清活动内容，是出行、祈福、祭祀还是实际修造。
2. 分别查对应宜忌，不以相邻事项替代。
3. 按资料核固定仪式日期与日时专条，并记录采用条件。
4. 检查主命及开始时点；如动作涉及土木，再增加空间和土煞层。

## 四、原课例子与拆解

PDF第229至230页先给“宜祈福”的一般选日步骤，又明确说五腊、三会、三元是道家固定日，与黄历有没有宜祈福不是一回事。它示范的是两套信息并列记录，不能把固定节日误算成某种每日神煞。

## 五、易错与适用边界

- 固定仪式日期与一般黄历筛日分开。第230页允许五腊按固定约定进行，即使另遇月破；不能据此推成所有活动在月破都可用。
- 清明仅拔草、轻整而不挖土，与挖土、取土、修坟分开；一旦动土就回相应专条。
- 第233页列四离四绝为大煞，第822页却以中煞解释某次用日，轻重存在不同讲法；不合成一条普遍可制的规则。
- 罗天大退的制法也有范围：第233页列以大进日月制时退、年退配两处大进，以及临官帝旺补助；出行午后权用不反推到上梁等所有用事。
- 同时有刑害时，该页不把名称数量简单累加；第234页的五不遇时还要看克日干，例如甲日午时须先遁出庚午。未列完整表时不凭一个“凶时”标签放大结果。

## 七、本章小结

- 先区分出行、祈福、祭祀及是否实际动土，分别查宜忌。
- 固定仪式日期单列，不与每日神煞混成一个名称。
- 祈福配日时阴阳，先定日干、时干并核五鼠遁。
- 截路空亡逐时起，再核同支、贵人、三合及木纳音例外。
- 出行俗忌与日时专忌分开，地方不采用的俗忌不升格成通则。
