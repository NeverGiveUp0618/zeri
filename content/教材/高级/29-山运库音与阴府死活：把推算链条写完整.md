# 第29章 山运库音与阴府死活：把推算链条写完整

> **前置**：先学 [第2章](#zr-02)、[第4章](#zr-04)、[第22章](#zr-22)。
> **本章解决什么**：能区分正体、洪范、山运纳音和年化气，识别单干双全外的条件。
> **本章的一句话**：先推出山运柱和纳音，再与年化气比较死活。

## 一、先把问题讲清楚

山运不是坐山正体五行的另一个名称。原课先用相应洪范五行找墓库，再按指定起遁法配出山运干支，最后查纳音。若中间把洪范属火误当正体属水，或把单干五行当纳音，后面的克山运与阴府死活都会跑偏。

阴府是否犯到，先由日课化气与山纳甲化气判断；死活则另比较年化气和山运纳音。原稿p1592以同、不同给出死活的说法，其他造宅段落对死阴府可否制化的表述又有差别。课程把定义、示例和分歧相邻列出，不把一句口诀扩成所有山运的最终算法。

这章训练的是能复现中间量：坐山、所用五行、墓库、起遁依据、山运柱、纳音、年化气、比较结果。某一步资料未说明，写待核，不用软件一个红绿标签替代。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 正体五行 | 用于龙山基础生克，不等于山运纳音 |
| 洪范五行 | 对应山运库音推算中的分类 |
| 山运干支 | 经指定墓库和起遁步骤求得 |
| 山运纳音 | 由完整山运柱查询 |
| 年化气 | 年干所属甲己土等化气组 |
| 死活比较 | 依原课定义与明确案例核，不跨步骤 |
| 争议 | 起遁时段、死阴府制化等不同段落需并列 |

### 洪范五行歌诀与原注异文分开看

p335原歌把二十四山分为：甲寅辰巽戌子辛申水；艮卯巳木；午壬丙乙火；乾亥酉丁金；丑癸坤庚未土。该页随后“注”把部分木与火、金与土并在一起，与歌诀不同。本节保留歌诀分组用于辨明输入，并明确原注有异文，未把错并组的注释做成自动算法。

原课壬山例明确以洪范火取墓戌，再推完整山运丙戌、查纳音土。这里“壬的正体水、洪范火、山运丙戌纳音土”是三个不同字段，不能只保留一个五行标签。

## 三、实际怎么检查

1. 先注明坐山和本次采用的洪范分类。
2. 找墓库，写清五虎遁或五鼠遁及其时间条件出处。
3. 推出山运干支，独立查纳音。
4. 再对年化气做死活比较，并回看单干、双全及专条限制。

## 四、原课例子与拆解

p1592例壬山，原稿给庚子年山运丙戌，纳音土；后文又以丁卯年乾山推辛丑纳音土，年丁壬化木，判为死阴府。它们展示了山运柱和纳音这两个中间量，不能跳成“乾金被丁火克”。后一例起遁带假设，复盘应把假设原样保留。

## 五、易错与适用边界

p1594谈冬至前后起遁不同，并夹有“自己分析”的归纳；这不是每条原口诀都共同明定的统一口径。不得把整理者解释升格为无争议规则。对起遁未定的候选课，只能保留中间结果与待核项。
