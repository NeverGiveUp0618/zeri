# 第32章 斗首第二层：旺衰、数量与五类山应用

> **前置**：先学 [第3章](#zr-03)、[第31章](#zr-31)。
> **本章解决什么**：能把五星名、番化、长生状态和数量条件连起来。
> **本章的一句话**：五星名称不定整课，仍核数量、位置、旺衰和制神力量。

## 一、先把问题讲清楚

斗首不是只认五星名。元辰重生旺，廉子多有泄气限制，破鬼尤其怕有位有气；同一地支对不同层五行又可能是不同长生状态。因此分析表至少保留山头、天干化气、A层五星、B层番化、地支状态五栏。

数量条件也很重要。原课讲廉子不宜多见，不能看它是吉星便追求四柱重重；破鬼的制法又要求廉子或武财有位有气，不能只见制神名就说已经制住。看完一柱，还要看四柱之间的关系和年月日时位置。

五类山逐组查：土六、火六、木四、金四、水四。墓库的阴宅阳宅取舍、个别早晚讲法不同以及示意课的历法问题，均保留原注。高级课明确说与正体有矛盾时以正体为主，斗首合不上不必强求。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 元辰 | 喜生旺有气；核是否被克泄 |
| 廉子 | 数量和位置须核，不宜盲目叠多 |
| 武财 | 制鬼等作用仍要求有位有气 |
| 贪官、破鬼 | 依具体条件论，不只看名字 |
| 墓库 | 原课阴宅、阳宅取舍不同，不能统一绿标 |
| 六土山 | 壬子巽巳辛戌 |
| 六火山 | 癸丑丙午乾亥 |
| 三组四山 | 艮寅丁未木；乙辰庚酉金；坤申甲卯水 |

## 三、实际怎么检查

1. 按上一章完成每柱A、B两层。
2. 分别查本层五行在地支和月令的状态，不偷换主语。
3. 核数量、位置、生克制化及制神是否有力。
4. 回正体与事项专条复核，示意格局必须再过历法。

## 四、原课例子与拆解

p1251以寅山、癸巳年癸亥月戊午日戊午时说明四廉子重现泄元辰，但这套年月日时本身需历法核验，按原课作关系示意，不纳入真实可用日课库。p1480再用四甲寅展示斗首与正体的差别，原文明确说只是示例。学习时先拆作用，再标“示意，不能直接实选”。

## 五、易错与适用边界

p1480原课自己注明“甲寅日没有甲寅时，只是举例”，不可把四甲寅当真实候选日课。p1237与高级课对有气状态的列举有差别，课程不据有争议列表机械出题。
