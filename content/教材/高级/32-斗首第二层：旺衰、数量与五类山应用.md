# 第32章 斗首第二层：旺衰、数量与五类山应用

> **前置**：先学 [第3章](#zr-03)、[第31章](#zr-31)。
> **本章解决什么**：能把五星名、番化、长生状态和数量条件连起来。
> **本章的一句话**：五星名称不定整课，仍核数量、位置、旺衰和制神力量。

## 一、先把问题讲清楚

斗首不是只认五星名。元辰重生旺，廉子多有泄气限制，破鬼尤其怕有位有气；同一地支对不同层五行又可能是不同长生状态。因此分析表至少保留山头、天干化气、A层五星、B层番化、地支状态五栏。

数量条件也很重要。原课讲廉子不宜多见，不能看它是吉星便追求四柱重重；破鬼的制法又要求廉子或武财有位有气，不能只见制神名就说已经制住。看完一柱，还要看四柱之间的关系和年月日时位置。

五类山逐组查：土六、火六、木四、金四、水四。墓库的阴宅阳宅取舍、个别早晚讲法不同以及示意课的历法问题，均保留原注。高级课明确说与正体有矛盾时以正体为主，斗首合不上不必强求。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 元辰 | 喜生旺有气；核是否被克泄 |
| 廉子 | 数量和位置须核，不宜盲目叠多 |
| 武财 | 制鬼等作用仍要求有位有气 |
| 贪官、破鬼 | 依具体条件论，不只看名字 |
| 墓库 | 原课阴宅、阳宅取舍不同，不能统一绿标 |
| 六土山 | 壬子巽巳辛戌 |
| 六火山 | 癸丑丙午乾亥 |
| 三组四山 | 艮寅丁未木；乙辰庚酉金；坤申甲卯水 |

### 五类山先找元辰，再核地支

| 山家斗首 | 元辰干组 | 本章所列代表有气地支 |
|---|---|---|
| 土六山 | 甲己 | 第1260页土与水论，不能擅自移成所有表都随火 |
| 火六山 | 戊癸 | 第1268页寅长生、辰冠带、巳临官、午帝旺 |
| 木四山 | 丁壬 | 第1276页元辰为木，再查木的状态 |
| 金四山 | 乙庚 | 第1282页巳长生、申临官、酉帝旺 |
| 水四山 | 丙辛 | 第1289页申长生、亥临官、子帝旺 |

查的是化气或番化后的五行，不是原来单干的正体长生。例如水山辛干先作丙辛水，再核水在亥的临官，不能直接照第3章辛阴干从子逆排的表。地支状态先写明是哪一层五行，才不会出现同一个“辛亥”被两套坐标混算。

第1237、1245页的一般有气名单含长生、冠带、临官、帝旺、墓、胎、养，无气列沐浴、衰、病、死、绝。后期第1474、1483页又把墓与衰败等并论，第1489页最终区分阴宅墓库有气、阳宅不吉；这些名单保留使用范围，不无条件合成统一的六相六气表。

### 星曜相互生克要看番化层

第1241页所列相生链是元辰生破鬼、破鬼生廉子、廉子生贪官、贪官生武财、武财生元辰；相克链是元辰克廉子、廉子克武财、武财克破鬼、破鬼克贪官、贪官克元辰。这里借A层名指其番化后的五行，所以不能与A层“我生廉子”放在同一栏直接比较。

元辰要生旺，所临支避免刑冲害及空亡，第1245页以候选日课的年柱查空亡，不用人物出生年柱或默认改成日柱。廉子只宜一，最好日时；破鬼忌有气、多见，若取武财关鬼，喜鬼居月而年日时武财有力，或有气廉子泄鬼。第1483页强调鬼帝旺而制神衰病死，数量再多也无用；并列官鬼混见又为另一项限制。

两武一元、两元一武或三武制贪官是该页列出的组合条件，不是只要凑齐数量就成立。仍核武财有位有气，以及山家、日家、阴府、旬空、日流、星曜、冲丁、燥火、刑冲、岁破三煞等专项。

## 三、实际怎么检查

1. 按上一章完成每柱A、B两层。
2. 分别查本层五行在地支和月令的状态，不偷换主语。
3. 核数量、位置、生克制化及制神是否有力。
4. 回正体与事项专条复核，示意格局必须再过历法。

## 四、原课例子与拆解

PDF第1251页以寅山、癸巳年癸亥月戊午日戊午时说明四廉子重现泄元辰。四柱阴阳配对、五虎遁与五鼠遁相符；原页未给公历日期和实际反馈，学习时用于拆解泄元辰关系，不补造使用结果。PDF第1480页的四甲寅则是原文明说的格局示例，年月干不合五虎遁，应标“示意，不能直接实选”。两例的资料性质须分开记录。

## 五、易错与适用边界

- 第1480页明确四甲寅只是举例，且年月、日时均不合对应遁法；不能为天地同流的外观补造公历。
- 第1282页金山元辰一行把番化写火，与同句乙庚金、元辰同我的定义相冲；本章按五组元辰主表核关系，同时保留该字误。
- 第1245页先写子山午向，随后却按午山火论戊癸为元辰，坐山对象前后不一；不据此把子山土改成火。
- 第1251页第二例时柱写戊午，却在解释中把庚称廉子，与土山廉子应金的关系未能对上。保留三甲扶山的说明，但不把原时柱与后文解释强拼成完整已核吉课。
- 第1483页末括注明相生相克词序可能口误，不能越过第1241页的层次解释另造一组规则。第1489页还规定斗首用于安葬登位、竖造行墙等节点，不能照搬到所有破土动作。

## 七、本章小结

- 每柱写A、B层五行及各自地支状态，不按原干本五行误查长生。
- 元辰看生旺与支受冲空，廉子看一位及日时位置。
- 关鬼与制贪官同时核位置、数量、制神和受制星力量。
- 墓库依阴阳宅及所用段落分开，不统一涂成吉或凶。
- 原例坐山或时柱前后不合时保留疑点，不编成可用整课。
