# 第33章 高级课复盘：太阳、月将与用时条件

> **前置**：先学 [第4章](#zr-04)、[第8章](#zr-08)、[第18章](#zr-18)、[第27章](#zr-27)。
> **本章解决什么**：能区分太阳到山、乌兔与贵人登天，不混用各自起算条件。
> **本章的一句话**：节令、月将、半时辰与到方按各自系统核实。

## 一、先把问题讲清楚

高级课增加太阳、太阴、乌兔、贵人登天等手段，它们不是给前面所有煞名再加一个统一的“可解”按钮。每种手段要明确时点、位置和所用表，不能只因软件有“太阳”两个字就把当下修方判作有制。

太阳到山到向与节令有关；月将又按相应中气运行；乌兔太阳有自身日起时法和到方法。表里一个字代表半个时辰、一个双山或一个方位时，都要写明单位，不能把“甲时”一概读成甲干所配的两个小时。

原课也对动土、局部修方和普通搬桌子分轻重。高级知识越多，越要回到实际动作。只因今年某宫有煞就让该方向所有生活行为停摆，不是这套课程应教的用法。未完整核实起法的项目保持查表，不冒充自动精算。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 节令太阳太阴 | 按对应到山到向表核节气和方位 |
| 贵人登天 | 日干贵人与月将等条件结合 |
| 乌兔太阳 | 采用自身表诀，不与其他太阳起法互换 |
| 用时单位 | 时辰、半时辰和方位字分别标注 |
| 施工性质 | 挖土、修造和普通摆设动作分开 |
| 结果 | 核实际到位，不用吉名替代 |

### 半时辰的单位先核清楚

p1110–1111的四大吉时双山表中，壬时对应子时前半段，癸时丑时前半段，艮时寅时前半段，甲时卯时前半段，乙时辰时前半段，巽时巳时前半段；丙、丁、坤、庚、辛、乾依次对应午、未、申、酉、戌、亥时前半段。这不是“时干是甲的完整时柱”之意。表中的钟点若用于实际地点，仍先核地方时间。

## 三、实际怎么检查

1. 给拟用吉神写全系统名称，而非只写“太阳”。
2. 查该法所用节令、月将、日期和时间单位。
3. 核到山、到向或到方是否符合当前动作。
4. 回专条看是否允许此制法，剩余待核项目继续保留。

## 四、原课例子与拆解

p1456例中谈癸山与小寒太阳太阴到山的条件，p1465则明确普通搬桌子与实际动土的区别。p1444又反复说明月将不按月柱的“节”切换。这三类信息应各记各的条件，不能混成“任何太阳到就能动土”。
