# 第34章 综合选课：候选比较、复核与交付记录

> **前置**：先学 [第9章](#zr-09)、[第10章](#zr-10)、[第22章](#zr-22)、[第26章](#zr-26)、[第29章](#zr-29)。
> **本章解决什么**：能完成一份注明条件、来源和待核项的日课学习记录。
> **本章的一句话**：同一检查范围内比较候选，未核项不能当作已通过。

## 一、先把问题讲清楚

综合实战不是把所有学过的规则一次性塞进每份日课，而是先按事项调用适用项目。开市不照抄安葬的仙命空亡，普通装修不冒称挖基，旧屋侧方开门不继续只看坐山。先把对象选对，检查才有意义。

课程整理了一张工作单：用事与动作、原始参数、候选日课、日家、山家、主命、专忌、可核制化、未核事项、最后复核。它是把前面章节串起来的学习工具，不是原书另有编号的十步秘诀。

比较两份候选时，先看是否有相同完整参数和相同核验范围。甲课只查一项无煞、乙课查十项发现一项问题，不能据标签数量说甲课更好。结论必须带适用范围：哪件事、哪几个人、什么山方、什么动作和时点。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 记录一 | 事项、地点、具体动作与执行时点 |
| 记录二 | 坐山兼向、动方、主命或仙命祭主 |
| 记录三 | 公历日期与四柱互核，年起月、日起时 |
| 记录四 | 日家、山家、主命、事项专忌逐项结果 |
| 记录五 | 制化的具体条件与依据 |
| 记录六 | 待核、异文、信息不足单列 |
| 记录七 | 候选之间在同一检查范围内比较 |

## 三、实际怎么检查

1. 先填工作单原始参数，缺项明确写缺。
2. 按事项展开对应章节，逐项填依据和结果。
3. 有煞先按专条处理，不用无关吉神或数量抵消。
4. 比较备选课，并回头复核日期四柱与实际执行节点。
5. 学习记录可先标“待核”，已读与实际会用分开记录。

### 手算练习：用已有规则做一次有限结论

给定子山午向，只知道年支午：能得出的局部结论是年支冲子山，属于岁破检查的一项。它不能告诉你主命是否相合、时辰是否有贵人，更不能生成一个可用候选日。再给旧屋巽方开门，则本次动作的主要空间参数已经变成巽方；前一项子山检查不能自动代替巽方修门。训练的是把已知结论的适用对象写清，不是对残缺信息猜整课结果。

## 四、原课例子与拆解

对照两类原例：辛丑福主开市由庚辰改辛巳时，体现保留日、调整时；午山阴府例庚子丁亥壬寅辛丑，体现先识别丁壬双全，再分死活。二者解决的问题不同，不能以“改时可用”作为处理所有双全、岁破或土煞的通则。

## 五、易错与适用边界

p1830安葬模板的公历农历字段有明显年代不一致；p1832第二候选课的干支与第一候选重复而日期已换。它们只能示范交付字段，不能直接推荐使用。站内分析器输出也是局部提示，未实现的项目必须列出。
