# 第34章 综合选课：候选比较、复核与交付记录

> **前置**：先学 [第9章](#zr-09)、[第10章](#zr-10)、[第22章](#zr-22)、[第26章](#zr-26)、[第29章](#zr-29)。
> **本章解决什么**：能完成一份注明条件、来源和待核项的日课学习记录。
> **本章的一句话**：同一检查范围内比较候选，未核项不能当作已通过。

## 一、先把问题讲清楚

综合实战不是把所有学过的规则一次性塞进每份日课，而是先按事项调用适用项目。开市不照抄安葬的仙命空亡，普通装修不冒称挖基，旧屋侧方开门不继续只看坐山。先把对象选对，检查才有意义。

课程整理了一张工作单：用事与动作、原始参数、候选日课、日家、山家、主命、专忌、可核制化、未核事项、最后复核。它是把前面章节串起来的学习工具，不是原书另有编号的十步秘诀。

比较两份候选时，先看是否有相同完整参数和相同核验范围。甲课只查一项无煞、乙课查十项发现一项问题，不能据标签数量说甲课更好。结论必须带适用范围：哪件事、哪几个人、什么山方、什么动作和时点。

## 二、规则与条件表

| 项目 | 判断与条件 |
|---|---|
| 记录一 | 事项、地点、具体动作与执行时点 |
| 记录二 | 坐山兼向、动方、主命或仙命祭主 |
| 记录三 | 公历日期与四柱互核，年起月、日起时 |
| 记录四 | 日家、山家、主命、事项专忌逐项结果 |
| 记录五 | 制化的具体条件与依据 |
| 记录六 | 待核、异文、信息不足单列 |
| 记录七 | 候选之间在同一检查范围内比较 |

### 一张能复盘的候选工作单

| 字段 | 自己要填写的内容 |
|---|---|
| 事项与节点 | 本次具体动作、正式开始时刻；先做准备与正式用事分开 |
| 地点与空间 | 房屋或墓地坐向兼针、实际动方、立极点及读数 |
| 人物 | 主事、主妇、其他参与者；仙命祭主或寿主分别填出生年干支 |
| 时间依据 | 公历、农历、交节情况、所用时间口径及四柱 |
| 日家与专忌 | 每项的起点、实际命中内容、适用事项和出处 |
| 山家与命家 | 分别写哪一柱对哪一山或哪一命，不能只写“冲” |
| 制化 | 用什么制、是否有力、数量位置是否满足，以及原文是否允许 |
| 剩余事项 | 缺资料、原文两说、未算表格与需要复核的历日 |
| 候选比较 | 同一事项同一检查范围下，逐条比较取舍理由 |

这是课程归纳的学习表，不是预测结果保证。每一格都可以先写待核，不能为了交一张完整表而编补缺失的兼向、公历或事后反馈。

## 三、实际怎么检查

1. 先填工作单原始参数，缺项明确写缺。
2. 按事项展开对应章节，逐项填依据和结果。
3. 有煞先按专条处理，不用无关吉神或数量抵消。
4. 比较备选课，并回头复核日期四柱与实际执行节点。
5. 学习记录可先标“待核”，已读与实际会用分开记录。

### 手算练习：用已有规则做一次有限结论

给定子山午向，只知道年支午：能得出的局部结论是年支冲子山，属于岁破检查的一项。它不能告诉你主命是否相合、时辰是否有贵人，更不能生成一个可用候选日。再给旧屋巽方开门，则本次动作的主要空间参数已经变成巽方；前一项子山检查不能自动代替巽方修门。训练的是把已知结论的适用对象写清，不是对残缺信息猜整课结果。

## 四、原课例子与拆解

对照两类原例：辛丑福主开市由庚辰改辛巳时，体现保留日、调整时；午山阴府例庚子丁亥壬寅辛丑，体现先识别丁壬双全，再分死活。二者解决的问题不同，不能以“改时可用”作为处理所有双全、岁破或土煞的通则。

## 五、易错与适用边界

- 第1830页公历写2024年10月9日，农历栏却写2020年九月初七；不先改其中某一栏迁就另一栏。须回历表核真实日期，模板只供看字段结构。
- 第1832页第二候选换成6月28日，四柱却仍照第一候选列寅月等字；其中壬午日乙巳时本身符合五鼠遁，但这不能证明第二候选整套日期也相符。不是只改月份就能当可用课，必须整套重新核对。
- 第1832页女命字段写甲戌，而夫星辛未、天嗣丙寅与甲干推配相容；字段相容并不能替模板中两个候选的历法错误背书。不同层分别验算。
- 站内分析器输出是已实现项目的局部提示。未给主命、兼向或未实现的神煞，既不算通过，也不靠减少红色标签来比较。
- 修改候选时，日期换了要重排月日时；只换时也须重查命煞、到方与执行节点，不能保留旧结论直接贴新课。

## 七、本章小结

- 先补原始参数，缺项与异文写在工作单上。
- 同样的检查范围才比较备选，不比标签数量或整齐程度。
- 改日改时后重算受影响项目，原结论不直接沿用。
- 模板只学字段结构，历日不合先暂缓，不补造结果。
- 已读、会演算和能独立核整课分别记录，笔记留下出处和待核点。
